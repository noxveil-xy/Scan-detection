# Scan-detection

**Scan-detection** --- учебный проект на Python для захвата, фильтрации
и первичной обработки сетевого трафика в Linux.

Проект разрабатывается в рамках практического изучения **сетевого
мониторинга, системного администрирования и кибербезопасности**.

> **Статус проекта: Beta / Active Development**
>
> Проект находится в активной разработке. Текущая версия является
> **бета-версией** и представляет собой фундамент для дальнейшей
> реализации системы обнаружения подозрительной сетевой активности.
>
> На данном этапе реализована только часть запланированной
> функциональности. Архитектура, модули и логика обработки трафика будут
> постепенно расширяться и изменяться в процессе разработки.

------------------------------------------------------------------------

## 🎯 Цель проекта

Основная идея проекта --- создать собственный инструмент, который
позволит:

-   захватывать сетевой трафик;
-   фильтровать интересующие пакеты;
-   получать информацию из сетевых пакетов;
-   сохранять события;
-   сортировать и обрабатывать полученные данные;
-   выявлять признаки сетевого сканирования;
-   в дальнейшем обнаруживать другую подозрительную активность.

Проект создаётся **с нуля в учебных целях**, чтобы на практике
разобраться в том, как работает захват сетевого трафика и как из
отдельных пакетов можно построить систему обнаружения сетевых событий.

# 🔄 Принцип работы текущей версии

На текущем этапе поток обработки выглядит следующим образом:

``` text
                  Network Interface
                         │
                         ▼
                    Scapy sniff()
                         │
                         ▼
                     BPF Filter
                         │
                         ▼
                  Filtered Packets
                         │
                         ▼
                   Packet Callback
                    ┌────┴────┐
                    │         │
                    ▼         ▼
                Console    files.py
                              │
                              ▼
                       var/buffer.txt
```

Scapy получает сетевые пакеты с выбранного интерфейса, после чего
BPF-фильтр позволяет отобрать интересующий трафик.

Полученный пакет передаётся в callback-функцию для дальнейшей обработки.

------------------------------------------------------------------------

# 🔎 Фильтрация трафика

В текущей версии используется BPF-фильтр:

``` text
tcp[tcpflags] & tcp-syn != 0
```

Он позволяет отбирать TCP-пакеты с установленным флагом `SYN`.

Принцип работы:

``` text
Network Traffic
      │
      ▼
   Scapy
      │
      ▼
 BPF filter
      │
      ├── TCP + SYN → обработка
      │
      └── Остальной трафик → отбрасывается
```

Фильтр является частью текущей тестовой реализации и в дальнейшем будет
изменён и расширен для задач обнаружения сетевого сканирования.

------------------------------------------------------------------------

# 📦 Работа с пакетами

После получения пакета проект передаёт его в обработчик.

В текущей версии пакет:

1.  принимается Scapy;
2.  передаётся callback-функции;
3.  выводится в консоль;
4.  сохраняется в буфер.

Упрощённая схема:

``` text
Packet
  │
  ▼
save_packets()
  │
  ├──► Console
  │
  └──► buffer.txt
```

В дальнейшем планируется отказаться от простого строкового представления
пакета и перейти к структурированному извлечению отдельных полей:

``` text
Source IP
Destination IP
Source Port
Destination Port
Protocol
TCP Flags
Timestamp
```
